내 구글 시트 연결하기

우리 반 정식 수업은 선생님 구글 시트를 서버로 써요. 학생 질문이 선생님 시트의 '질문 기록' 탭에 차곡차곡 쌓이고, 선생님이 지우기 전까지 남아요. 처음 한 번만 하면 되고, 10분 정도 걸려요.

먼저 써 보고 싶다면: 체험 서버

체험 서버로 게임 만들기
  1. 1

    질문 기차 시트 사본 만들기

    1. 개인 Gmail 계정으로 로그인한 상태에서 아래 사본 만들기 버튼을 눌러요. (학교 업무용 계정은 관리자가 막아 두었을 수 있어요)
    2. "문서 사본을 만드시겠습니까?" 화면에서 사본 만들기를 누르면, 서버 코드가 들어 있는 시트가 내 드라이브에 생겨요.
    3. 시트 이름은 알아보기 쉽게 바꿔도 괜찮아요. 예: 질문 기차 게임 기록
    사본 만들기 새 탭에서 열려요. 이 화면은 그대로 두세요.
    사본 만들기 링크가 아직 준비되지 않았어요아래 사본 만들기가 안 될 때: 직접 만들기를 펼쳐 따라 해 주세요.
  2. 2

    웹 앱으로 배포하기

    1. 복사된 시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 눌러요. 새 창에 코드 편집기가 열려요. (코드는 이미 들어 있어요)
    2. 오른쪽 위 배포 → 새 배포를 눌러요.
    3. "유형 선택" 옆 톱니바퀴를 눌러 웹 앱을 골라요.
    4. 다음 사용자 인증 정보로 실행: 나 / 액세스 권한이 있는 사용자: 모든 사용자로 정하고 배포를 눌러요.
      "Google 계정이 있는 모든 사용자"가 아니라 그냥 "모든 사용자"예요. 그래야 학생 태블릿이 로그인 없이 들어와요.
    5. 액세스 승인 → 내 계정을 골라요. "Google에서 확인하지 않은 앱" 화면이 나오면 왼쪽 아래 고급 → 질문 기차 서버(으)로 이동(안전하지 않음) → 허용을 눌러요.
    6. 화면에 나온 웹 앱 URL을 복사해요. https://script.google.com/macros/s/…/exec 처럼 /exec로 끝나요.
    경고 화면이 나와도 괜찮아요선생님 드라이브에 복사된 코드라서 구글 심사를 받지 않았다는 뜻이에요. 이 코드는 복사한 시트 하나에만 접근하고, 다른 파일이나 메일은 볼 수 없어요. 게임 만들기·시작·지우기 같은 선생님 기능은 다음 단계에서 정하는 비밀번호로 막혀 있어요.
  3. 3

    웹 앱 주소 붙여 넣고 선생님 비밀번호 정하기

    처음 연결할 때 정한 비밀번호가 이 시트의 선생님 비밀번호가 돼요. 다른 컴퓨터에서는 같은 주소와 비밀번호를 넣으면 돼요.
사본 만들기가 안 될 때: 직접 만들기

사본 만들기 대신 새 시트에 코드를 직접 붙여 넣는 방법이에요. 아래 1~3을 한 뒤 위의 2. 웹 앱으로 배포하기부터 이어서 해요.

  1. 개인 Gmail로 새 구글 시트를 만들어요.
  2. 시트 메뉴 확장 프로그램 → Apps Script를 열고, 위쪽 "제목 없는 프로젝트"를 눌러 이름을 질문 기차 서버로 바꿔요.
  3. 편집기의 function myFunction() { }을 모두 지우고, 아래 코드 복사하기로 복사한 코드를 붙여 넣은 뒤 저장(💾 또는 Ctrl+S)을 눌러요.

알아 두면 좋아요

      
    
        
  • 질문 기록: 시트의 '질문 기록' 탭에 게임 코드·판·모둠·칸·질문·쓴 사람이 쌓여요. 탭 이름과 열 순서는 바꾸지 말고, 필요 없는 줄은 지워도 괜찮아요.
    • 
        
  • 새 버전 코드로 바꿀 때: 편집기에 새 코드를 붙여 넣고 저장한 뒤 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포를 눌러요. 웹 앱 주소가 바뀌지 않아요. ("새 배포"를 다시 누르면 주소가 바뀌어요)
    • 
        
  • 비밀번호를 잊었을 때: Apps Script 편집기 위쪽 함수 칸에서 resetTeacherPassword를 골라 ▷ 실행한 뒤, 이 화면에서 새 비밀번호를 정해요.
    • 
        
  • 다른 컴퓨터에서 수업할 때: 그 컴퓨터에서 이 화면을 열고 같은 웹 앱 주소와 비밀번호를 넣어요.
    • 
        
  • 동시 사용: 모둠 태블릿 8대와 선생님 화면 한 대를 기준으로 만들었어요. 선생님마다 자기 시트를 쓰는 것을 권해요.
